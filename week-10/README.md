# 인공지능기초 10주차: 텍스트 임베딩 심화 실습

도서 및 텍스트 데이터의 임베딩 변환 및 유사도 기반 분석 실습 프로젝트입니다.

## 구성
- `textembeddingbooks.py`: 텍스트 임베딩 파이프라인 스크립트
- `docs/Week10_Report.pdf`: 10주차 실습 보고서
- `.env.example`: 환경변수 템플릿

## 실행 방법
1. 패키지 설치
   ```bash
   pip install openai python-dotenv
   ```
2. `.env` 파일 설정 후 실행
   ```bash
   python textembeddingbooks.py
   ```
